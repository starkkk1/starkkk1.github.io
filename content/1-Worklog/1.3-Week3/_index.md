# Week 03 Worklog - AWS Foundations and Cost Planning

**Project:** Tomato leaf disease detection on AWS  
**Period:** Week 03 working days 1 to 5

### Week Objectives:
- Map the project requirements to EC2, S3 and CloudWatch.
- Choose a deployment Region and review the available AWS credits.
- Establish a budget approach for a temporary learning environment.

### Tasks to be carried out this week:
| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 1 | Explore the AWS Console and identify compute, storage, networking and monitoring services relevant to the machine learning demonstration. | W03 D1 | W03 D1 | Amazon EC2 getting started |
| 2 | Define the responsibilities of Amazon EC2, Amazon S3 and Amazon CloudWatch. Sketch how model storage, compute and monitoring connect. | W03 D2 | W03 D2 | Amazon S3 user guide |
| 3 | Select Asia Pacific Sydney, ap-southeast-2, for the deployment. Review regional resource availability and keep the project resources in a consistent Region. | W03 D3 | W03 D3 | Amazon EC2 getting started |
| 4 | Review the credit balance, expiration and eligible usage. Identify compute, EBS storage, public IPv4 and monitoring as separate potential cost sources. | W03 D4 | W03 D4 | AWS Budgets guide |
| 5 | Prepare a monthly cost budget and notification plan. Define a practice of stopping the instance between sessions and reviewing retained storage costs. | W03 D5 | W03 D5 | AWS Budgets guide |

### Achievements:
- Defined an AWS architecture centered on EC2, S3 and CloudWatch.
- Selected Sydney as the project Region and reviewed credit constraints.
- Prepared a cost control plan for the learning environment.
