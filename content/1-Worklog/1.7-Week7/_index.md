# Week 07 Worklog - Amazon EC2 Provisioning and Access

**Project:** Tomato leaf disease detection on AWS  
**Period:** Week 07 working days 1 to 5

### Week Objectives:
- Provision an EC2 instance suitable for CPU model inference.
- Prepare storage and secure administrative access.
- Understand instance status checks and lifecycle operations.

### Tasks to be carried out this week:
| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 1 | Review available x86_64 instance types, memory requirements and regional availability. Choose a suitable option within the project budget. | W07 D1 | W07 D1 | Amazon EC2 getting started |
| 2 | Launch an Amazon Linux 2023 instance with EBS storage. Attach the selected subnet, Security Group and EC2 instance profile. | W07 D2 | W07 D2 | Amazon EC2 getting started |
| 3 | Prepare the SSH key on Windows and restrict private key file permissions. Connect with the correct instance user and current public IPv4 address. | W07 D3 | W07 D3 | Amazon EC2 getting started |
| 4 | Inspect operating system details, free memory, CPU capacity and disk space. Confirm instance status checks before preparing model files. | W07 D4 | W07 D4 | Amazon EC2 getting started |
| 5 | Review Start, Stop, Reboot and Terminate operations. Record which resources persist after Stop and why public IPv4 can change on Start. | W07 D5 | W07 D5 | EC2 stop and start guide |

### Achievements:
- Prepared the EC2 compute environment for model inference.
- Established secure SSH access and reviewed host resource capacity.
- Documented lifecycle operations and their storage and IP implications.
